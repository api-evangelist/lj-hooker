# LJ Hooker

> LJ Hooker is one of the largest residential and commercial real estate brokerage and property management networks in Australia and New Zealand. Founded in Maroubra, Sydney in 1928, the franchise network reports 390 businesses and around 4,000 sales professionals, property managers and support staff, facilitated more than AUD$20 billion in property transactions during 2024, and manages roughly 100,000 properties valued at about AUD$82 billion on behalf of investors. **LJ Hooker publishes no public developer API**: there is no developer portal, no API documentation, no API terms of use, no SDKs, no webhooks and no partner or listing-data-feed programme on any LJ Hooker domain. This file is generated by API Evangelist from the public LJ Hooker web surface; it is not published by LJ Hooker.

## API posture

- No developer portal, API reference, or API terms of use exists on any LJ Hooker domain. The `developer.`, `developers.`, `api.` and `docs.` subdomains of ljhooker.com.au do not resolve in DNS.
- No OpenAPI, Swagger, AsyncAPI, GraphQL, OData `$metadata`, Postman collection or MCP server is served anywhere.
- No `/.well-known/` discovery document is served on any brand host, and no `/llms.txt` is published (42 anonymous probes across 6 hosts, all 404 or 403 — see `well-known/lj-hooker-well-known.yml`).
- RESO (the Real Estate Standards Organization Web API and Data Dictionary) is a North American, NAR-driven regime with no Australian footprint. LJ Hooker does not appear in the RESO certificates directory, and RESO certification is not applicable to an Australian brokerage.
- A real but **undocumented** website backend exists at `https://api01.ljx.com.au`, operated by the third-party web vendor behind the property-search front end (an AWS API Gateway consumed by an OpenAPI-Generator JavaScript client). It is anonymously reachable but carries no documentation, no key, no published contract and no terms permitting third-party use, so it is deliberately not listed as an API. See `review.yml`.
- Australia's machine-readable property rails sit elsewhere: the REA Group (realestate.com.au) and Domain portal duopoly for listing distribution, PEXA for electronic conveyancing settlement, state land registries, and PropTrack / CoreLogic for valuation data. LJ Hooker is a consumer of that stack, not a publisher of a standard.
